# 星界资源与美术规范

物品、晶体、母岩与 Curios 空槽图标采用 Minecraft 风格的原生 **16×16 像素贴图**。以轮廓、切面、刻痕和少量高光区分材质，不使用柔化、抗锯齿或高分辨率细节冒充 16×16。

## 资源位置

| 内容 | 位置 |
| --- | --- |
| 游戏资源 | `src/main/resources/assets/deeprealm_4th/` |
| 源图 | `art/source/item/`、`block/`、`slot/`、`gui/` |
| 物品／方块模型 | `models/item/`、`models/block/` |
| 方块状态 | `blockstates/` |
| 中英文文本 | `lang/zh_cn.json`、`lang/en_us.json` |

透明物品与晶体贴图使用 RGBA，像素 alpha 为全透明或全不透明。母岩采用无透明空洞的方块材质。星之源与星浆晶体使用深蓝晶面、青色脉络和金色夹杂；四个生长阶段各有独立 16×16 贴图。

GUI 背景、槽框、锤子、箭头和鼠标等图标通过贴图渲染。界面贴图按整体布局使用相应尺寸，以硬边像素保持统一美术风格；物品资源的 16×16 尺寸要求不套用到整张 GUI 背景。

## 六分数配色

颜色集中由 `astral.score.AstralScoreColors` 提供，分数面板、容器预览、填充物说明和条件中的晶石名称共用。

| 分数 | 颜色 | RGB |
| --- | --- | --- |
| 力量 | 红 | `#E76868` |
| 敏捷 | 青绿 | `#55CBB3` |
| 智力 | 蓝 | `#71A9ED` |
| 体质 | 琥珀 | `#E6B85C` |
| 感应 | 淡紫 | `#BCA1EC` |
| 魔力 | 洋红 | `#E182D9` |

Java 使用 `AstralScoreColors.name/gain/color` 构造带色文本，不在语言文件嵌入颜色码。JEI 配方中直接绘制的文字使用黑色；物品 tooltip 继续遵循物品自身的分数配色。

## 模型与 Curios 图标

星之源使用 `minecraft:block/cube_all`；晶芽和晶簇使用 `minecraft:block/cross` 与 cutout 渲染，物品栏使用平面图标。投影框架通过模型叠层显示已吸收材料，基础资源仍按像素风格制作。

专属槽配置 `data/deeprealm_4th/curios/slots/base_container.json` 引用 `deeprealm_4th:slot/base_container`，对应 `textures/slot/base_container.png`。

## 制作工具与预览

已有生成脚本用于对应资源批次；调用前确认其写入范围，避免覆盖已手工修改的图像或模型。GUI 修改在现有贴图基础上进行。

- 初阶物品处理：`scripts/prepare_astral_item_textures.ps1`，支持 `-ItemIds` 指定范围。
- 扩展与进阶物品：`scripts/generate_astral_expansion_sprites.py`、`generate_astral_progression_sprites.py`。
- 空槽、皮革垫与 GUI：`scripts/generate_astral_curios_slot.py`、`generate_forging_pad_sprite.py`、`generate_gui_textures.py`。
- 星之源模型与数据：`scripts/generate_star_source_resources.py`；图像生成说明保存在 `art/source/star_source_prompts.txt`。

现有预览用于查看资源，不作为自动覆盖源图的依据：[初阶物品](assets/astral-sprites-16x-preview.png)、[扩展物品](assets/astral-expansion-16x-preview.png)、[进阶材料](assets/astral-progression-16x-preview.png)、[Curios 空槽](assets/astral-curios-slot-preview.png)、[星之源与晶体](assets/star-source-16x-preview.png)。

## 紫黑缺失贴图排查

先核对模型引用、PNG 路径和实际安装 JAR 中的资源。若日志仍读取已经删除的模型，却找不到 JAR 中确实存在的新模型，检查整合包的资源索引缓存。

本项目曾遇到 Lightspeed 复用同版本 JAR 的旧索引：`lightspeed-cache/<MC版本>/hasResource/`、`namespaces/`、`resourceLists/` 中本模组对应的缓存仍保存旧资源列表。退出游戏后清理这些可重建的本模组缓存，再启动重建索引；不要据此删除世界或其他模组文件。
