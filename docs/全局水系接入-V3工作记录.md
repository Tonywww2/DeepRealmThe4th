## 接缝问题的处理方向

V1/V2 的独立方形父域缺少外部汇水条件。V3 不将这些有限图直接拼贴：采用世界坐标唯一的抖动采样点和局部可证明的空圆邻接，严格下降的地形势决定唯一排水去向，逆向遍历完整上游集合。自然终点及流域身份由图决定，区块/缓存边界不参与选择。

首轮 Gabriel 子图测试虽通过一致性检查，但主干过短；扩大到全局 Delaunay 邻接，并降低小丘对排水势的影响。空圆条件依据 [CGAL 官方文档](https://doc.cgal.org/latest/Triangulation_2/classCGAL_1_1Delaunay__triangulation__2.html)，实现没有引入或复制 CGAL。抖动格点有已知覆盖半径 R，空圆半径不会大于 R，端点与阻挡点距离不会超过 2R，因此有限邻域足以判定全局边，而不是裁切一张有限图。

势由有界地形高度和有限整数平局等级组成，因此不存在环或无限严格下降路径。对异常大的完整流域使用确定性的容量拒绝，不能把工作预算用完的位置伪装为河口。缓存仅影响速度；重建、逆序、并行及跨区块查询必须一致。

沿既定连接走廊细化河线，局部地形与非对称两岸控制形态，避免统一倒圆或直接把粗三角网画成道路。地形改动有开挖/抬岸上限，保留 Y60 中心断崖、75% 名义陆地、10% 径向增幅、无内部虚空裂隙及海洋三格保护。

封闭终点采用小型内流湖候选，建立长期供水、湖面蒸发与有限基底渗漏容量的预算。参数是游戏尺度的无量纲近似；不声称真实物理水文。无安全终点、过大积水或过量开山时拒绝整条流域，不制造断支流或虚空瀑布。

## 接入与验收

1. 独立算法测试：跨区块/缓存顺序、图无环、水量收支、相交、纵剖面、地形改动限值。
2. 将实际注册群系气候作为不可变输入，保持 H0 → 基础群系 → 气候 → 水系 → 最终列/群系的单向依赖。
3. `fillFromNoise`、高度、基础列、地物/结构保护使用共同模型；新世界使用新算法版本，旧配置缺版本时保留旧算法。
4. 双端新世界验证实际河水、汇口、终点、区块接缝、流水 tick、重载、海洋墙，以及群系/地物/生物/结构入口。
5. 记录性能、实际算法样品和开发包，不把只通过编译当作接入完成。

## 已落地的模型

- 世界采样间距 64 格，位置有种子抖动。排水势使用与 H0 共享的宏观起伏和有限山脊，去掉土丘对主干的过度切碎；最终表面仍保留小尺度起伏。V2 的旧地形构造入口保持不变。
- 完整流域最多 4096 节点。缓存可淘汰，不截断上游，也不在窗口边缘造假河口。细化走廊约束同时考虑相邻流域，主支流水位沿程不升高。
- 河流两岸宽度独立，河头渐窄，河床约 1～5 格深。岸坡服从邻近上游水位的短距离封水约束，避免水位台阶形成跨岸流水；限制过度切山/抬坝。
- 内流湖通过真实 H0 低地的连通生长产生湾汊；面积按实际方块中心重测。遇到分配窗口边界或不足的渗漏容量时拒绝候选，不画方形截边或统一圆湖。
- 区块填充、基础列、高度查询共用 `terrainBlock`。原生温度决定山顶雪块和水面冰；原生 placed features、结构与生物入口仍执行，生成期保护不能堵死河道或挖穿封水岸坡。
- 新配置版本为 3；缺少版本字段的配置解码为 1，测试其结果与原有 `TerrainProfile` 一致。此项不是旧存档自动无缝升级承诺。

## 复现与材料

使用对应端导出的 `run/<loader>-server/hydrology-prototype/climate.tsv`，运行 `verifyGlobalHydrology`。真实世界验证脚本为 `scripts/Test-HydrologyRuntime.ps1`，仅接受本项目无人 seed=42 的 V9 测试服：

```powershell
.\scripts\Test-HydrologyRuntime.ps1 -Loader forge -Phase Climate
.\scripts\Test-HydrologyRuntime.ps1 -Loader forge -Phase Prepare
# 让服务器运行至少 200 游戏 tick，再检查
.\scripts\Test-HydrologyRuntime.ps1 -Loader forge -Phase Check
# save-all flush、正常停服、重新启动后，再运行 Check
.\scripts\Test-HydrologyRuntime.ps1 -Loader forge -Phase Cleanup
```

另有 Geometry / Biomes / Ecology / Structures 阶段。将 loader 替换为 neoforge 可运行另一端。Prepare 只生成自然区块、记录本次新增的强加载和安排原版流水更新；Cleanup 只释放本次拥有的强加载，保留存档与探针记录。报告在 `build/reports/hydrology-v3/<loader>/runtime/` 和 `run/<loader>-server/hydrology-v3/`。

样品：`build/reports/hydrology-v3/<loader>/01-V3最终地形列.png`、`02-V3河谷近景.png`。它们直接绘制最终地形列中的水/土，不是额外画上的河线，也不是客户端截图。

限制：无动态降水、地下水或海洋外排模拟；不安全的大湖/深切割流域整体拒绝。群系池热湿组成会改变河网密度。真实客户端飞行观感、第三方模组组合及长期并发探索性能尚未验收。

性能边界：本机实服本轮启动约 29～37 秒；批量群系搜索/区块验证可能占用主线程十几秒，因此验证命令仅对指定无人存档开放。这不是玩家探索延迟或客户端帧率的测量。
