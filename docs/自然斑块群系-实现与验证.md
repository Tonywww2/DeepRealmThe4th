# 0.1.4：自然斑块群系

## 修改内容

旧版群系条带有两个来源：`TerrainProfile.climate` 沿用含随机角度扰动的漩涡坐标，距中心越远拉伸越明显；`SpiralBiomeSource` 又把单一噪声按排序切分为多个群系，使相邻噪声区间成为平行带。地形主题本身也由流向噪声阈值划分，因此只修改池内的群系选择仍不足以消除条带。

新增纯算法 `BiomeClimate`：

- 使用旋转后的世界 X/Z 坐标和有界位置扰动，不把群系坐标绕中心拉长。
- 主题分区尺度约 260～340 格，池内群系尺度 190 格；两级都用多个独立的连续噪声场竞争，叠加较小尺度的边界变化。没有规则网格分区、硬多边形细胞或逐区块随机选择。
- 四支陆地仍分别属于干旱、下界、温带/热带和海洋大类；平原偏好低起伏区域，高山必须处于真实高地。河流、海岸、海水深浅、岛屿和火山保留实际地形/水体约束，因此这些群系仍可能自然呈带状。
- 主题只在高度/水体计算结束后替换，沙子、红沙/陶瓦、下界基底和草地等材料与主题同步；具体群系的生态基底、地物、刷怪和结构仍通过实际 `SpiralBiomeSource` 选择结果。
- tag 扩展和空池 fallback 保留，候选按资源 ID 的独立噪声评分，不依赖 tag 枚举顺序；根 tag 未分类扩展群系有单独的斑块入口，且不覆盖海岸防水墙。

没有修改 0.1.3 的山峰高度、河床、水位、底部厚度、虚空轮廓、中心尺寸、Y60 断崖及径向增幅。群系和材料变化仍需要新世界查看；已生成的旧区块不会自动更新。

## 自动回归

`BiomeDistributionVerification` 加入两端 `verifyTerrain`：

- 三个种子 `0,42,-739221`，X/Z `[-2048,2048]`、步长 13，共 299568 列；29 个默认群系全部可达。
- 排除生态标签，仅对高度、底部、水位/流体、陆地标志、边界距离、防水墙和变体编号计算指纹，严格等于旧版 JAR 的 `41b0d2de1d26ec92`。
- 测试 tag 顺序无关、不同种子变化、并发/逆序查询与根 tag 扩展斑块可达性。
- 保留原有坡度阈值和几何/封水断言，没有因改群系而放宽高度检查。生态标签变化会改变按主题分组的坡度统计，不应把这种分组变化解释为再次修改了地形高度。

为单独检测旧坐标的远处碎裂，固定下界四群系池，不裁剪陆地或地形主题，三种种子、每圈 360 个方向，比较相隔 8 格的 X/Z 邻点：

| 半径 512 / 1024 / 2048 | 81.51% | 89.06% |

该指标用于检查远近尺度稳定性，不是整个维度的群系面积或“自然度评分”。结果见 `build/reports/terrain/biome-verification.txt` 和 `build/reports/terrain-neoforge/biome-verification.txt`。

## 复现

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\graalvm-jdk-21.0.5+9.1'
$env:GRADLE_USER_HOME = Join-Path $PWD '.gradle-user-home'
.\gradlew.bat :1.20.1-forge:build :1.21.1-neoforge:build --no-build-cache --console=plain
```

启动对应开发服务器后，使用 `scripts/Test-VortexRuntime.ps1 -Loader forge|neoforge -Phase Biomes` 检查实际群系；其他阶段为 `Geometry`、`Ecology`、`Structures`、`Prime`、`Fluids`。这些生成/生态探针仅应在所规定的新验证存档运行。

旧图由保留的 0.1.3 JAR 提供地形和旧字段，并复用当时精确的排序分段选择逻辑，可按下列命令重建：

```powershell
& "$env:JAVA_HOME/bin/java.exe" '-Djava.awt.headless=true' -cp 'versions/1.21.1-neoforge/build/libs/deep_realm_the_forth-neoforge-0.1.3+1.21.1.jar;versions/1.20.1-forge/build/classes/java/test;versions/1.20.1-forge/build/classes/java/main' com.tony.deeprealmtheforth.worldgen.BiomeDistributionVerification build/reports/vortex-v7-before baseline
```
