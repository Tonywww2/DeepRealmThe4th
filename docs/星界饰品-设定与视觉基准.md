# 星界饰品：设定与视觉基准

状态：设定框架草案。宝石、星体和星座是系统的基础设定：**宝石承载星体力量，星座决定组合规则**。本文记录已确定的关系与后续必须统一的规则，不把视觉表现当成设定本身。

## 已定锚点

核心物品叫“星界躯体”，宝石、星体和星座共同构成其基础设定。宝石承载星体力量，星座决定组合规则。星界躯体是可装备的容器；内部填充物产生六项分数，职业勋章再将分数转换为实际属性。战士勋章读取力量分数。分数自身没有属性效果。这些是机制与命名的已确认部分。

三者不能只承担图标、配色或装饰的职责。正式内容还要定义具体宝石与星体的对应方式、星座的构成和触发条件、组合效果的数值。下面的表现提案不能替代这些设定与规则。

## 设定层级与表现提案

| 元素 | 必须定义的设定职责 | 可使用的视觉表达 |
| --- | --- | --- |
| 宝石 | 承载星体力量的物件；具体品种与承载关系待定 | 晶面、颜色、内含物、物品图标 |
| 星体 | 宝石所承载力量的来源；具体星体名录和效果待定 | 光点、轨道、容器外形 |
| 星座 | 决定组合规则；具体判定图案和效果待定 | 连线、排列、组合提示 |
| 勋章 | 如何读取分数并产生属性 | 与普通宝石不同的徽记轮廓 |

目前已确认存在“相邻指定填充物则加分”的规则类型，可作为最小组合规则示例。正式星座规则如何由格子位置或填充物种类判定仍待确认；不能让玩家误以为所有邻接格总有加成。关闭格保持清楚的不可放置外观；若格内保留了配置变更前的物品，应额外显示可取回提示。

### 星界躯体

容器物品贴图只需简单、清楚，能在 16×16 像素里辨认即可。12×9 是配置矩阵的几何范围，不必画满 108 个发光点。基础 6×5 开放区居中，画面重心应在该区域；边缘暗格比开放格低对比度。更复杂的宝石、星体与星座关系应由填充物、规则和说明承担，不强加到容器小图标上。

### 填充物

普通填充物首先要能与勋章区分。宝石切面可作为共同形状，六项分数通过有限的形态差异辅助区分；颜色不能是唯一信息。这里**暂不建立**红宝石＝力量之类的正式对应，具体对应要按最终基础设定决定。条件填充物可在提示或详细界面中展示“触发条件 → 结果”，但未触发时也应能辨认物品本身。

已确认的“力量晶石”每件增加 1 点力量分数，允许多件叠加。它属于宝石承载星体力量的体系，但对应的具体星体、获取方式和更细的物件来历仍待设定；不要只凭名称或临时贴图推断这些关系。

### 战士勋章

图标应比普通宝石更接近“徽记”：清晰的外环、中心刻痕和较少的晶面。外环可呼应星体轨道，中心图形可呼应力量这一读取来源。容器图标本身仍保持简单。无需先设定战士组织、军阶或历史。玩家提示精确写出“力量最低按 0 分计算，最终攻击力提升 `ln(1 + 力量分数/15) × 100%`”，并给出力量 15 时约 +69.3% 的示例，标明只在星界躯体装备时生效。

## 命名层级

目前确定的正式名包括“星界躯体”“力量晶石”“战士勋章”和六项分数。可用的命名词根包括晶面、星点、轨道、连线、刻痕、辉光；它们是创作词库，不是已注册内容。新物品定名时先确定效果和图标，再检查名称是否能区分同系列其他物品。玩家文本依照 [饰品系统文案指南](饰品系统文案指南.md) 编写。

## 尚待设定决定

- 宝石承载哪种星体力量、星体与六分数是否有固定对应，星座与职业是否一一对应。
- 星座的构成方式、触发规则、组合效果与首个正式样例。
- 星界躯体的来历、制造方式及其与深境四层的关系。
- 职业勋章是否代表组织、誓约、训练成果，或只是功能性命名。
- 首批普通填充物的正式名、形态、获取方式与分数值。
- 最终图标和 GUI 资源的色板、像素规格及音效方向。

在这些内容确认前，不把提案写成物品故事、进度描述或游戏内百科事实。
