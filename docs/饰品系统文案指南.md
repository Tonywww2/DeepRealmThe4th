# 饰品系统文案指南

适用于物品名、tooltip、界面、JEI 描述和相关说明。玩家文本采用简短、直接的句子；较长的规则解释、公式及获取说明放入指南。

## 已确认的设定

宝石承载星体力量，星座决定组合规则。深境四层影响材料获取与来历；星体与生态股没有一一对应关系，内置填充物效果不随所在生态股改变。

南十字座、望远镜座、南三角座分别关联相邻、数量、转换。具体星体名录、制造者、组织、年代和起源尚未确定，不以“失落文明”等套语补全。附属的 `addon:*`、`kubejs:*` 技术示例不构成正式设定。

## 名称与语气

- 使用当前中文语言文件中的名称，统一“星界躯体”“晶石”“晶核”“勋章”“星浆”“投影框架”“组合锻造”等术语。
- 中文使用自然的现代书面语，以晶面、刻痕、棱线、光泽等具体性质表达意象。
- 分数名称固定为力量、敏捷、智力、体质、感应、魔力；机制叙述需要区分分数与攻击力等属性。
- 玩家可见文本不出现类名、NBT、注册表、`otheronme` 等实现细节。
- 语言文件不嵌入 `§` 颜色码；六分数交给统一颜色 API 渲染。

## 简短 tooltip

内容按实际需要排列：基础增减 → 条件或转换 → 生效类型／冲突 → 必要操作提示。已经由界面明确表达的说明不重复出现。

| 场景 | 写法 |
| --- | --- |
| 基础分 | 力量 +1 |
| 生效类型 | 可叠加／唯一佩戴／唯一效果 |
| 玩家条件 | 经验等级 >30：智力 +2 |
| 相邻条件 | 与体质晶石相邻：感应 +1 |
| 比例加分 | 按基础力量的 20% 加分，最多 +4 |
| 转换 | 扣除非负力量的 1/3；按扣除量的 1.5 倍获得体质 |
| 战士勋章 | 根据力量获得攻击力加成 |
| 星浆操作 | 使用玻璃瓶采集成熟星浆晶体 |
| 禁用槽位 | 禁用 |

相邻的具体定义、唯一效果的副本处理等公共规则在指南解释；物品只补充区别于公共规则的条件。转换必须交代扣除来源与所得目标，百分比必须明确基础分或最终属性及上限。

默认 tooltip 不写获取地点或“来源：……”；不追加“分数不提供属性”“关闭格子保留物品”等重复说明。精确属性由容器、勋章预览及 Curios 属性行显示。获取途径记录在玩法指南与配方展示中。

## 公式与数值

战士勋章按 `ln(1+max(0,力量)/15)×100%` 提高最终攻击力；力量 15 约 +69.3%。规则文档可给公式，普通 tooltip 保持简短。负力量按 0 处理。

规则中的 `0.10` 表示 10%；固定属性加算与最终值乘算需准确区分。生命值使用点数，20 点等于默认十颗心。等级与生命阈值保持实现中的严格／包含边界，不把 `>` 翻成 `≥`。

## 中英文与占位符

中文 `lang/zh_cn.json` 是措辞基准，英文 `en_us.json` 同步含义与术语。资源 ID 不翻译，玩家名称完整本地化。

- 修改 `%s` 等占位符时，同步两种语言和 `Component.translatable` 调用中的参数数量、类型、顺序。
- 格式化字符串中的字面百分号按调用方式使用 `%%`。
- 空值表示该行需要移除；同时删除对应显示调用，避免显示未翻译键。
- 配置可改变宽高、格数与入口维度，玩家文本不写死这些默认值。
- JEI 配方直接绘制的文字使用黑色；tooltip 的六分数使用[统一配色](星界资源与美术规范.md#六分数配色)。

## 审校

核对当前注册定义、条件边界、来源与目标、数值单位、占位符，以及实际模型和贴图。未确定内容在设计提案中明确标注，确认并实施后再写入现行说明。
