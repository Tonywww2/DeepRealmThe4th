# 星界物品：16×16 贴图制作记录

当前正式物品共有三十三件：星界躯体、二十九种晶石和三枚勋章。首批十二张图由内置 `image_gen` 分别生成透明像素风原图，保存在 `art/source/item/`；`scripts/prepare_astral_item_textures.ps1` 按透明区域裁切、最近邻缩为 16×16、收敛至 20 色，并把每个像素的 alpha 固定为全透明或全不透明，输出到 `src/main/resources/assets/deeprealm_4th/textures/item/`。若源图已经是 16×16，该脚本直接复制，以保留像素画构图。物品模型引用本模组贴图。脚本的 `-ItemIds` 参数可只处理指定物品，不重做已完成的贴图。

| 物品 | 生成提示词的主体与约束 |
| --- | --- |
| `base_container` | A simple dark indigo oval wearable vessel, silver rim, tiny pale star at center, hollow interior; centered front-facing Minecraft inventory sprite. |
| `strength_gem` | A stout faceted ruby-red hexagonal gemstone, warm crimson facets, small embedded four-point stellar glint; centered front-facing Minecraft inventory sprite. |
| `warrior_medal` | A sturdy bronze-gold octagonal badge, dark recessed center, simple star and vertical blade mark; centered front-facing Minecraft inventory sprite. |
| `agility_gem` | Teal narrow faceted gem; diagonal motion streak. |
| `intelligence_gem` | Blue squared gem; bright central reflection. |
| `constitution_gem` | Amber broad gem; sturdy horizontal facets. |
| `perception_gem` | Pale violet triangular gem; eye-like central cut. |
| `magic_gem` | Deep magenta gem; luminous inner core. |
| `arid_ridge_gem` | Ochre gem; dry ridge grooves and a pale edge. |
| `magma_vein_gem` | Dark volcanic gem; bright orange molten fissures. |
| `canopy_gem` | Green gem; raised leaf-vein facet. |
| `tidal_gem` | Cyan gem; layered wave facets. |

每张图的完整生成约束相同：单个物品、真正透明的背景和角落、以 16×16 像素网格构图、清晰方形像素边缘、无抗锯齿／柔和渐变／投影／文字／UI 框／水印。图案约占 12～13 格。首批十二张成品见[首批最近邻放大预览](assets/astral-sprites-16x-preview.png)。

新增二十一件物品使用 `scripts/generate_astral_expansion_sprites.py` 的逐像素绘制方案：八件第二批晶石、十一件比例／玩家条件晶石、疾行勋章及守御勋章。脚本一次生成对应的 `art/source/item/` 原图、资源贴图、物品模型和[新增物品最近邻放大预览](assets/astral-expansion-16x-preview.png)。各图共用六分数的颜色家族，但以刻痕、切面和轮廓区分，不把生态或星体写成一一对应。运行 `scripts/verify_astral_item_textures.ps1` 可检查所有已注册物品的模型、贴图路径、16×16 尺寸、二值透明度及不超过 24 色的调色板；目前三十三张均通过检查。

Curios 专属槽位另有一张 16×16 空槽图标：`assets/deeprealm_4th/textures/slot/base_container.png`。它用灰紫色空心轮廓呼应星界躯体的瓶形，上有短颈，中央以五像素星点标记用途，背景全透明。`scripts/generate_astral_curios_slot.py` 生成源图、游戏资源和[放大预览](assets/astral-curios-slot-preview.png)；槽位 JSON 引用 `deeprealm_4th:slot/base_container`。
