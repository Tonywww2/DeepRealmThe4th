# 星界进阶材料与双工艺：设计与实现

状态：**首版实现中**。本文记录深境四层的星浆、组合锻造、投影框架组合合成及十件进阶填充物。正式星座名为南十字座、望远镜座、南三角座。现有已实现内容见[首批扩展](星界填充物-首批扩展设计稿.md)、[第二批](星界填充物-第二批设计稿.md)和[比例与玩家条件](星界填充物-比例与玩家条件设计稿.md)。

## 设定与流程

已确定的关系是**宝石承载星体力量，星座决定组合规则**。星浆是尚未稳定的星力材料：它被宝石或晶胚固定后参与精细制作；投影记录材料的叠放次序与方向；碎片是投影经反复锻造后的稳定材料。不预设制造者、文明、具体星体名录，也不把四条生态陆地股与四颗星体绑定。

```text
在深境四层探索 → 采集星浆、寻找现有晶石
                   ├→ 星浆晶胚 → 组合锻造 → 固相星浆
                   └→ 投影框架 → 有向叠放 → 星座投影
                                                └→ 组合锻造 → 星座碎片
星座投影／碎片 + 星浆材料 + 已有晶石 → 进阶填充物
```

深境四层影响**获取和物件来历**，不参与佩戴时的分数条件。带出深境四层后，填充物照常生效。容器仍是每件一格；星座的佩戴规则只检查开放且有效格中的**正交相邻**或**有效数量**，不增加摆图案系统。投影工艺的有向叠放属于制作流程，与佩戴布局是两件事。

生存入口：紫菘果、龙息、下界之星和紫水晶碎片可合成瓶装拟态星浆；手持它落入配置允许维度的虚空后进入深境四层。服务端配置 travel.void_entry_dimensions 默认仅含 minecraft:the_end，可填多个维度 ID，空列表禁用入口。星界躯体可用拟态星浆、金锭和紫水晶碎片合成。

## 材料与取得

| 物品 | 取得／制作 | 用途 | 设计约束 |
| --- | --- | --- | --- |
| 星浆 | 使用玻璃瓶右击成熟星浆晶体，获得一瓶星浆 | 晶胚、投影、部分进阶填充物 | 可堆叠的瓶装物品；晶体采集后消失，母岩可重新生长。 |
| 星之源 | 深境四层虚空晶洞的内壁自然生成 | 生长星浆晶体的母岩 | 不加入其他维度的生成或战利品；沿用紫水晶母岩的不可搬运、开采不掉落规则。 |
| 星浆晶体 | 打碎成熟星浆晶簇，每簇掉落一个 | 星浆晶体材料 | 小型、中型和大型晶芽不掉材料；材料可堆叠至 64，暂不增设加工配方。 |
| 投影框架 | 工作台：四角玻璃板、四边铜锭、中心紫水晶碎片 | 承载有序材料；最多九次叠放 | 可在进入深境四层之前制作；配方不消耗星浆，避免循环依赖。 |
| 星浆晶胚 | 工作台无序：星浆 ×1、紫水晶碎片 ×1 | 通用半成品 | 仍含一份星浆；精确贴图和物品形态随星浆定稿。 |
| 透星片 | 投影框架上依次叠放玻璃板、星浆，两步方向见下文 | 星座投影的共同底材；展示工艺也能制作普通材料 | 不是填充物，不提供分数。 |
| 固相星浆 | 星浆晶胚、紫水晶碎片和星浆组合锻造，锤击 2 次、消耗 3 级 | 高阶填充物的通用辅料 | 不赋予自身佩戴效果。 |

虚空晶洞使用原版 `minecraft:geode` 地物类型，位于 Y=-32..128，约每 64 个虚空区块尝试一座；不会穿入陆地。晶洞为空心的方解石与紫水晶外壳，内壁放置 2–4 个星之源及不同阶段的星浆晶体，替换原有紫水晶母岩和星浆露点。

星之源沿用紫水晶的随机刻生长节奏：每次随机刻有 1/5 概率选取一个方向，在空气或源水中生长小型晶芽；后续随机刻依次生长为中型、大型、成熟晶簇。晶体支持六向附着及含水。成熟后可选择打碎取得材料，或装瓶取得星浆；装瓶不会同时掉落晶体材料，也不破坏母岩。含水晶体采集后保留原处的水。

## 新配方类型一：组合锻造

锻造皮革垫由 4 个皮革和 2 根线在工作台合成。

在铁砧顶面放置薄方块“锻造皮革垫”，右键打开 4×3 输入格。垫中的物品在关闭界面和区块重载后保留；移除垫时返还垫与已存物品。配方对输入格无序匹配，每条原料占一格，`count` 可要求该格消耗多个物品。额外的未匹配物品会阻止配方。服务端匹配成功后，右侧显示产物名称、锤子按钮及锤击进度。

点击锤子 `clicks` 次后完成配方，默认 3 次；每次有效点击有 `cooldown` 刻间隔，默认 10 刻。冷却中点击仍能按按钮，但不计进度，播放较轻的声音。经验成本 `levels` 默认 0，只在最后一次有效锤击时一次扣除。成品直接进入玩家背包，满时掉落。关闭界面重置锤击进度，不影响垫内材料。`name_key` 可覆盖产物显示名称；省略时使用物品原名。工艺不消耗铁砧耐久。

首批六条配方沿用原先的基础物品和各轮材料，每种一件，改为无序输入。锤击次数采用原轮数，经验保留原累计成本：2、3、4、5 次分别消耗 3、7、15、31 级。重复原料合并为一格并提高 `count`。这只是内置配方的数值，不强制附属配方遵循翻倍公式。

| 产物 | 无序输入：基础物品＋材料 | 锤击 | 完成时等级 |
| --- | --- | ---: | ---: |
| 固相星浆 | 星浆晶胚、紫水晶碎片、星浆 | 2 | 3 |
| 南十字座的碎片 | 南十字座的投影、力量晶石、感应晶石、固相星浆 | 3 | 7 |
| 望远镜座的碎片 | 望远镜座的投影、魔力晶石、感应晶石、智力晶石、固相星浆 | 4 | 15 |
| 南三角座的碎片 | 南三角座的投影、体质晶石、敏捷晶石、魔力晶石、星浆、固相星浆 | 5 | 31 |
| 刻阶晶核 | 待锻刻阶晶胚、智力晶石、刻阶晶石、紫水晶碎片、固相星浆 | 4 | 15 |
| 盛息晶核 | 待锻盛息晶胚、体质晶石、盛息晶石、紫水晶碎片、固相星浆 | 4 | 15 |

## 新配方类型二：投影框架组合合成

框架储存 `0..9` 条记录。每条记录包括**材料、操作方向、位置序号**；服务器验证下一步与任一配方前缀相符后，才吸收一件材料。方向定义：

- **材料 → 框架**：拿材料点击物品栏中的框架；材料减少一件，框架留在原槽。
- **框架 → 材料**：拿框架点击物品栏中的材料；材料减少一件，框架继续留在手上。

这分别对应物品栏的 `otheronme` 和 `meonother` 操作方向。点击后若顺序、材料或方向不符，**拒绝这一步，既不吞材料也不清空框架**。不同配方可以共享开头步骤；服务端在每一步保留候选，最后一步只允许唯一完整配方。叠放 `2..9` 次完成后输出成品并消耗框架。

未完成的框架可在 3×3 工作台**无序拆解**，产出空框架，并通过配方余物返还已吸收的材料。每件材料的完整物品数据都须保存与返还；未完成的框架不得与空框架堆叠。Shift 点击、背包满、掉线重登、配方重载仍需客户端实测无丢失或复制。

框架基础图标保持 **16×16 像素画**。已吸收材料不能只靠九个微小像素图标辨认：持有或物品栏模型中呈现框内逐步增加的材料缩影与方向标记，tooltip 按顺序完整列出“第几步／材料／方向”，并显示当前匹配的配方和下一步候选。模型只显示**已吸收**的材料；不提前泄露未知配方的后续步骤。材料贴图仍各自独立 16×16，模型可以叠层渲染，不要求把九张完整材质压进一张 16×16 PNG。

## 星座投影与碎片

“南十字座、望远镜座、南三角座”是**正式星座名**，分别表达相邻、数量、转换三类组合逻辑。星体名录另议；不把星座名字反推为某颗星体或某条生态股。

方向缩写：`材→框`、`框→材`。每行步骤必须从左到右完成，材料均消耗一件。

| 投影 | 框架上的步骤 | 接续锻造 | 制作侧重点 |
| --- | --- | --- | --- |
| 南十字座的投影 | 力量晶石 `材→框` → 感应晶石 `框→材` → 透星片 `材→框` | 组合锻造锤击 3 次 → **南十字座的碎片**，共耗 7 级 | 与相邻晶石呼应；不要求在容器内摆出直线。 |
| 望远镜座的投影 | 魔力晶石 `材→框` → 感应晶石 `材→框` → 智力晶石 `框→材` → 透星片 `框→材` | 组合锻造锤击 4 次 → **望远镜座的碎片**，共耗 15 级 | 与有效晶石数量呼应。 |
| 南三角座的投影 | 体质晶石 `框→材` → 敏捷晶石 `材→框` → 魔力晶石 `框→材` → 透星片 `材→框` | 组合锻造锤击 5 次 → **南三角座的碎片**，共耗 31 级 | 与分数转换呼应。 |

普通材料的组合合成样例：**透星片**为玻璃板 `材→框` → 星浆 `框→材`，共两步。普通填充物也可以参与组合锻造，见下节条件晶核；这两种新配方均非星座专用。

## 进阶填充物

下面十件均为**一格填充物**。百分比读取基础阶段快照 `B[分数]`；固定条件加分与百分比加分在同一阶段结算，不互相递归放大；转换在其后按格盘顺序处理。所有相邻和数量条件只统计开放、有效物品。未特别标注者为**唯一效果**：同 ID 可放多件，只有第一件生效。与现有初级晶石的冲突采用有向抑制：高阶物品在场时，指定低阶物品可以保留在格中但暂不生效，移走高阶物品后自动恢复。

| 层级／名称 | 基础分与追加规则 | 取得方式 | 限制／设计目的 |
| --- | --- | --- | --- |
| 投影：南十字座棱晶 | 力量 +3；与**感应晶石**正交相邻时，再得力量 +2 | 南十字座投影＋星浆晶胚＋力量晶石，工作台无序合成 | 最多 +5；让单件高值仍需要摆放取舍。 |
| 投影：聚辉晶心 | 魔力 +3；有效的**魔力晶石至少 2 件**时，智力 +2 | 望远镜座投影＋星浆晶胚＋魔力晶石，工作台无序合成 | 最多 +5；数量条件不因超过两件重复触发。 |
| 投影：南三角座晶心 | 体质 +3；转换阶段扣除当时**非负体质的 1/4**，按所扣分数的 1.5 倍增加敏捷 | 南三角座投影＋星浆晶胚＋体质晶石，工作台无序合成 | 守御与疾行勋章之间的取舍；必须在 tooltip 同时写扣除与所得。 |
| 锻造：刻阶晶核 | 智力 +3；经验等级 **>30** 时额外智力 +3 | 刻阶晶石＋固相星浆先工作台无序合成“待锻刻阶晶胚”，再组合锻造锤击 4 次，共 15 级 | 合计最多 +6；与刻阶晶石有向冲突，低阶品可保留但暂不生效。 |
| 锻造：盛息晶核 | 体质 +3；当前生命值 **>16 点** 时额外体质 +3 | 盛息晶石＋固相星浆先工作台无序合成“待锻盛息晶胚”，再组合锻造锤击 4 次，共 15 级 | 合计最多 +6；与盛息晶石有向冲突。 |
| 碎片：南十字座棱核 | 力量 +4；正交相邻至少 **2 件 `#deeprealm_4th:astral/gems`** 物品时，感应 +3 | 南十字座碎片＋固相星浆＋力量晶石，框架三步组合 | 最多 +7；与南十字座棱晶有向冲突。tag 检测支持不同晶石邻居。 |
| 碎片：望远镜座晶核 | 魔力 +4；有效的**魔力晶石至少 3 件**时，智力 +3 | 望远镜座碎片＋固相星浆＋魔力晶石，框架三步组合 | 最多 +7；与聚辉晶心有向冲突。 |
| 碎片：南三角座晶核 | 体质 +4；转换阶段扣除当时**非负体质的 1/3**，按所扣分数的 **2 倍**增加敏捷 | 南三角座碎片＋固相星浆＋体质晶石，框架三步组合 | 与南三角座晶心有向冲突；高倍率以实际体质损失换得。 |
| 碎片：照映晶核 | 魔力 +3；正交相邻至少 **2 件 `#deeprealm_4th:astral/medals`** 时，按 `min(6, max(0,B[魔力]) × 50%)` 额外获得魔力 | 望远镜座碎片＋固相星浆＋透星片，框架三步组合 | 单件比例收益最多 +6；勋章读最终分数，不被此晶核直接改变。 |
| 汇合：六衡晶核 | 六项分数各 +1，无条件额外分 | 三种星座碎片＋固相星浆，框架四步组合 | **唯一佩戴**；同 ID 只能放一件，总共 +6 分，但分散到六项。 |

高阶组合合成步骤如下，继续让铁砧配方只有一个基础材料。缩写与上文相同；三步或四步均在新框架上从头进行，不能把制作投影时的记录带进碎片：

| 产物 | 有向叠放步骤 |
| --- | --- |
| 南十字座棱核 | 南十字座碎片 `框→材` → 固相星浆 `材→框` → 力量晶石 `框→材` |
| 望远镜座晶核 | 望远镜座碎片 `材→框` → 固相星浆 `框→材` → 魔力晶石 `材→框` |
| 南三角座晶核 | 南三角座碎片 `框→材` → 固相星浆 `框→材` → 体质晶石 `材→框` |
| 照映晶核 | 望远镜座碎片 `材→框` → 固相星浆 `材→框` → 透星片 `框→材` |
| 六衡晶核 | 南十字座碎片 `材→框` → 望远镜座碎片 `框→材` → 南三角座碎片 `材→框` → 固相星浆 `框→材` |

数值校验例：南十字座棱核旁有两件不同的有效晶石时，得力量 +4、感应 +3；只剩一件时只有力量 +4。若 `B[魔力]=10` 且照映晶核两侧各邻接一枚有效勋章，额外魔力为 +5；`B[魔力]=20` 时额外魔力受单件上限限制为 +6。南三角座晶核在转换前体质为 9、敏捷为 0 时，扣除体质 3、增加敏捷 6，结束后体质 6、敏捷 6；如先有其他转换晶石，则按容器格序读取它留下的体质。

高阶力量与战士勋章会互相放大收益，因此高阶晶石以唯一效果、明确条件和有向冲突控制重复叠加；正式上线前需按 0、15、30 力量等点位分别验证攻击力。六衡晶核虽总分高，但单项 +1，不直接替代专精晶石。任何新勋章的属性公式另行讨论，本稿不私自指定星体与属性对应。

## 发现、提示与开发接入

- 星之源、各阶段星浆晶体、晶体材料、晶胚、透星片、固相星浆、投影、碎片和进阶填充物都进入本模组创造栏，并有中英文名称和 **16×16** 贴图。四阶段晶体分别使用独立贴图，在 16×16 画布上绘制由小到大的轮廓；方块采用原版紫水晶的交叉面模型，物品栏使用平面图标。框架允许模型叠层显示动态内容；基础物品图标仍为 16×16。
- 两类工艺的内置配方由 datagen 生成，Java／KubeJS 附属也可添加数据配方。组合锻造可声明 1–12 条无序输入、每格数量、锤击次数、冷却、经验成本和可选名称键；投影组合可声明 2–9 条 `(材料, 方向)` 步骤。JEI 分别显示输入图标和工艺信息。
- 星浆 tooltip 写“使用玻璃瓶采集成熟星浆晶体”，不显示来源型提示。进阶晶石 tooltip 依次显示基础分、条件／转换、冲突或唯一类型；六项分数沿用全局颜色。不重复“分数不提供属性”。
- 深境四层自然生成的星浆及现有晶石来源需分别检查主世界、下界、末地和其他自定义维度；仅创造栏与 `/give` 可越过自然获取限制。两版都须验证物品栏两种叠放方向、满背包拆解与皮革垫持久输入。

## 已确认的实现决定

- 星浆为可堆叠的瓶装物品；手持玻璃瓶采集成熟星浆晶体后晶体消失，由星之源重新生长。成熟晶体也可打碎取得晶体材料。
- 组合锻造使用铁砧上的薄皮革垫和 4×3 持久输入格；配方无序，首批锤击 2–5 次，完成时一次扣除 3–31 级，不损耗铁砧。
- 未完成投影框架在 3×3 工作台拆解时返还框架与已吸收材料；完成组合时消耗框架。
- 正式星座名为南十字座、望远镜座、南三角座，对应相邻、数量、转换规则。
- 拟态星浆由紫菘果、龙息、下界之星、紫水晶碎片合成；星界躯体需要它合成。持有拟态星浆落入虚空的来源维度由服务端配置 `travel.void_entry_dimensions` 控制，默认仅 `minecraft:the_end`，空列表关闭入口。

Forge 1.20.1 与 NeoForge 1.21.1 均已通过代码编译、资源生成，并在临时服务端确认加载组合锻造 6 条和投影组合 9 条配方。投影框架操作、皮革垫界面、声音、满背包输出和双端联机仍需客户端实测。
