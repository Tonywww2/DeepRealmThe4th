# 0.1.5：雪线、河岸与海滩

## 实现

- 雪线：取消固定 Y120 的判定。约 210 格与 39 格的连续噪声共同改变局部积雪阈值，形成高低不一的雪缘和局部裸岩，不使用逐方块白噪声。
- 河道：用主干、支流曲线的最近距离决定河床和水面；源头采用圆滑端点，支流增宽并增加弯曲。水深由岸边向中央渐变，而非一进入河流就统一下切数格。
- 河谷：连续谷地包络与现有丘陵平滑相接，同时采样相邻流域，避免流域格线成为地形接缝。低岸坡按水位托起，河床和近岸使用连续斑块的沙、砾石、黏土。
- 海岛：主要采用世界坐标的多尺度噪声与有界位置扰动，减少岛形沿旋涡方向的统一拉伸。海床、浅水、低缓沙滩、岛内丘陵连续过渡；沙滩宽度和草沙交界都受独立噪声影响，不再按狭窄的固定高度带上色。
- 封水：天然岛岸不再额外生成统一 Y65 的凸起护圈，三格厚砂岩加沙顶的保护层改为埋入原有岸坡。海洋与虚空相邻处仍保留保护墙，墙顶有低频高度变化；不把水体直接暴露给虚空。

中心直径 112 格、核心虚空直径 48 格、中心外起始 Y60、径向增幅 10%、75% 名义陆地及旋转参数保持不变。本轮没有改变陆地/虚空遮罩，也没有重新引入陆地股内部裂隙。岸墙顶允许位于水面同层 Y64：该层为实体方块，水不能横向流入；不必为了封水再统一抬高一格。

## 与原版的关系

检查了本地目标版本的原生源码，重点是 TerrainProvider.overworldOffset / 侵蚀样条、NoiseRouterData 的山谷输入以及 SurfaceRuleData 的水位、坡度与噪声材质规则。原版现代河谷与基础密度场和气候共同工作，并没有适合直接替换本维度柱模型的单个“河流地物”入口。

本次借鉴连续谷地与水位相关地表的处理思路，**没有直接调用原版河流生成器**，也没有把整套主世界噪声生成器移植进来。曲线流域仍为本项目算法；原有原生地物、结构、生物生成路径继续保留。

## 安装与限制

需要使用对应 Minecraft/加载器的 0.1.5 JAR，并在**新世界**检查变化。旧区块不会更新，继续探索旧世界可能在新旧算法的交界出现接缝。

自然度没有客观“通过分数”；这些测试用于排除固定雪线、平顶岛圈、窄硬岸和漏水等具体问题。尚未完成玩家视角的客户端视觉验收、长期生态/性能及第三方地物/结构兼容性测试。河网是有限流域的低落差模型，不是完整的全球侵蚀与水文模拟。
