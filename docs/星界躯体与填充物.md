# 星界躯体与填充物

宝石承载星体力量，星座决定组合规则。星体与四条生态陆地股没有一一对应关系；深境四层承担材料获取与来历设定，内置填充物的效果不按玩家所在生态股改变。南十字座、望远镜座、南三角座分别关联相邻、数量、转换；佩戴布局采用相邻和数量条件。

## 容器与生效

星界躯体 `deeprealm_4th:base_container` 是 Curios 专属 `base_container` 槽中的容器。直接使用或在物品栏右键可打开；每件填充物占一格，装备时由容器通过 Curios 应用勋章属性。未佩戴时界面可只读计算预览。

默认外框为 12×9，中心 6×5 开放，共 30 格。配置可调整宽、高及 `X`／`.` 矩阵，详细格式见[开发者指南](星界躯体-开发者指南.md#基础容器的网格尺寸)。禁用格中的物品保留但不参与结算，重新开放后恢复。

| 生效类型 | 行为 |
| --- | --- |
| 可叠加 `STACKABLE` | 同 ID 多件各自生效 |
| 唯一佩戴 `UNIQUE_WORN` | 同 ID 只能放入一件 |
| 唯一效果 `UNIQUE_EFFECT` | 可放多件，同 ID 只结算第一件有效副本 |

有向冲突允许物品保留，抑制来源移除后自动恢复。相邻只检查上下左右开放且有效的格子；数量规则也只统计有效填充物，禁用、冲突失效和重复失效的物品不计入。

## 分数与结算

六分数为力量、敏捷、智力、体质、感应、魔力，名称和数值共用[全局配色](星界资源与美术规范.md#六分数配色)。小数不提前取整，勋章把最终分数换算为 Minecraft 属性。

所有填充物使用逐格节点引擎：解析各格 → 计算全部基础分 → 声明读取来源 → 按依赖计算最终分 → 汇总 → 勋章转属性。固定规则通过同一引擎的适配器执行：条件和比例加分读取本轮基础分，转换按格序处理修正结果，勋章读取最终汇总。自定义节点可声明基础分或最终分依赖，详见 [API 指南](星界宝石系统-API扩展开发者指南.md)。

下表中的 `B[分数]` 是本轮有效填充物基础分合计。比例收益使用 `max(0,B)`，达到单件上限后截断；同一轮附加分不会递归放大。转换扣除当时可用的非负来源分数，再按倍率增加目标。

## 职业勋章

三枚内置勋章均为唯一效果，可并用，默认启用。令 `s` 为对应最终分数：

| 勋章 | ID | 属性规则 |
| --- | --- | --- |
| 战士勋章 | `warrior_medal` | 最终攻击力提高 `ln(1+max(0,s)/15)×100%`，`s` 为力量；15 分约 +69.3% |
| 疾行勋章 | `wayfarer_medal` | 最终移动速度提高 `min(30%, max(0,s)×1%)`，`s` 为敏捷 |
| 守御勋章 | `warden_medal` | 最大生命值固定增加 `min(10, max(0,s)×0.5)` 点，`s` 为体质 |

勋章通过工作台制作：金锭、紫水晶碎片、两颗对应基础晶石与职业器具。战士使用力量晶石／铁剑，疾行使用敏捷晶石／指南针，守御使用体质晶石／盾牌。确切摆放见配方或 JEI。

## 深境四层宝箱获取

本模组的宝箱修饰器先检查维度为 `deeprealm_4th:fourth_layer`，再检查目标原版战利品表；其他维度使用相同表时也不会追加晶石。每个目标宝箱独立进行三次掷取：

- `1/3`：追加一件基础晶石，六种等权。
- `1/9`：追加一件该结构对应主题晶石。
- `1/4`：追加一件该结构稀有候选，池内等权。

| 结构／战利品表后缀 `minecraft:chests/` | 主题晶石 | 稀有候选 |
| --- | --- | --- |
| 沙漠神殿 `desert_pyramid` | 旱棱 | 棱桥、双镜、移衡、裂锋、脉幅、折映、群镜、刻阶、余锋、夜明 |
| 下界要塞 `nether_bridge` | 熔脉 | 棱桥、余烬、折返、裂锋、脉幅、连脉、环纹、余锋 |
| 丛林神庙 `jungle_temple` | 林冠 | 游纹、余烬、移衡、沉锚、游影、连脉、群镜、刻阶、盛息、盈辉 |
| 沉船 `shipwreck_map`／`shipwreck_supply`／`shipwreck_treasure` | 潮汐 | 双镜、游纹、折返、沉锚、游影、折映、环纹、盛息、盈辉、夜明 |

三次可同时成功，每次追加一件，保留原有战利品。初阶 29 种晶石来自这些池；10 件进阶填充物由工艺制作。三枚勋章不进入宝箱池。创造栏和 `/give` 可用于开发。
