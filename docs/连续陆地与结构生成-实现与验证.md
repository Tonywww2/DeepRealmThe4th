# 连续陆地与结构生成 · 0.1.2

## 改动与尺寸口径

- 移除 `VortexField` 的 `tear/gate/split` 内部裂隙遮罩及其边距侵蚀，不再在各支内部切出虚空。保留随机相位、边缘曲折、带宽、丘陵、山脊与河流。
- 中心按圆形**总直径** 7 区块（112 格）实现，中央虚空直径 3 区块（48 格），中心仍是 `(8,8)`。对应 `plunge_radius=56`、`core_radius=24`，不是半径 7/3 区块，也不是把 49/9 个方形区块全部纳入圆内。已说明此默认解释；如果要求严格方形区块对齐，应改边界算法，不只改半径。
- 旧代码实际使用半径 64/16 格，而非严格 3×3 中心；因此外缘是按目标直径重新标定，不是声称旧半径 64 扩大到 56。虚空直径由 32 增至 48 格。
- 断崖径向基线在半径 30～56 格从 Y=-52 升到 Y=60；外围增幅仍为原始曲线的 10%。旧区块不自动更新，建议新建世界。

## 结构实现

1. `createState` 改为原生 `createForNormal`，使用动态注册表结构集。spacing、separation、salt、概率、排斥区、环形位置和群系过滤继续生效；没有结构 ID 白名单。
2. 复用原生 `createStructures` 选择起点和部件，再逐列检查各部件 X/Z 包围盒。跨越虚空的起点整体标为无效，引用与 `/locate` 使用同一结果。Forge 的 `getAllStarts()` 是只读视图，须通过原生 setter 更新。
3. 按 generation step 执行结构，再执行同阶段的群系地物。保持注册表顺序、原生 decoration/feature seed、跨区块 writable bounding box 和 `StructureStart.placeInChunk`。继续避开主世界/下界混合地物的 FeatureSorter 排序冲突。
4. 结构写入保护允许挖掘房间和高建筑，但保留虚空、底壳、海床、砂岩护岸和盆地外流体保护，并阻止挖穿河流/熔岩池的封水岸。玩家建造与其他维度不受生成期保护限制。
5. 世界必须开启 `generate-structures`。外部结构需有结构集、能选中本维度群系且满足自身条件；不承诺专用生成器依赖直接兼容。未额外移植 NoiseBasedChunkGenerator 的 Beardifier 地形塑形；低于浮空底壳的结构部分仍会被保护规则限制。
