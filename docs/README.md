## 维护约定

- 功能变更时同步更新对应指南、示例和文档入口；已落地内容直接记录当前行为。
- 被当前实现替代的设计稿、旧版本副本和一次性验证报告从目录移除；历史改动通过 Git 查询。
- 未确定的设定不写成事实。新的设计提案单独说明待确认内容，批准并实施后合并到现行指南。
- 用户未要求测试时，只执行改动必需的最小验证，遵循根目录 [AGENTS.md](../AGENTS.md)。
