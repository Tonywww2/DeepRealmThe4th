# 星界材料与工艺

本指南记录当前内置材料与配方。两类工艺分别为组合锻造 `deeprealm_4th:combination_forging`、投影组合 `deeprealm_4th:projection_combining`，均有 JEI 展示。配方数据格式与附属接入见[开发者指南](星界躯体-开发者指南.md#星浆入口与进阶工艺)。

## 入口与材料

紫菘果、龙息、下界之星和紫水晶碎片可合成拟态星浆。手持拟态星浆落入配置允许维度的虚空可进入深境四层；`travel.void_entry_dimensions` 默认仅含 `minecraft:the_end`，空列表禁用。星界躯体使用拟态星浆、金锭和紫水晶碎片合成。

| 材料／道具 | ID 后缀 | 获取与用途 |
| --- | --- | --- |
| 星之源 | `star_source` | 深境四层虚空晶洞的母岩，生长星浆晶体；开采不掉落 |
| 星浆晶体 | `star_slurry_crystal` | 打碎成熟晶簇获得，每簇一个；小、中、大型晶芽不掉材料 |
| 星浆 | `star_slurry` | 用玻璃瓶右键成熟晶簇获得一瓶；瓶装可堆叠至 16 |
| 拟态星浆 | `mimetic_star_slurry` | 虚空旅行材料，瓶装可堆叠至 16 |
| 投影框架 | `projection_frame` | 工作台四角玻璃板、四边铜锭、中心紫水晶碎片；用于有向叠放 |
| 锻造皮革垫 | `forging_pad` | 工作台四块皮革、两根线；放在铁砧顶面操作 |
| 星浆晶胚 | `star_slurry_blank` | 星浆与紫水晶碎片工作台无序合成 |
| 透星片 | `astral_lens` | 玻璃板与星浆投影组合，作为投影底材 |
| 固相星浆 | `stabilized_star_slurry` | 星浆晶胚与材料组合锻造，作为进阶辅料 |
| 待锻刻阶晶胚／待锻盛息晶胚 | `unfinished_etched_blank`／`unfinished_breath_blank` | 对应条件晶石与固相星浆工作台无序合成，再组合锻造 |

晶洞使用原版 `minecraft:geode`，生成范围 Y=-32..128，仅在深境四层虚空生成，内壁有 2–4 个星之源。母岩随机刻生长小型 → 中型 → 大型 → 成熟星浆晶体，支持六向附着与含水。装瓶后晶体消失，含水时保留水，由母岩重新生长；装瓶和打碎是两种收获方式，一次采集只取得对应产物。

## 组合锻造

右键铁砧上的锻造皮革垫打开 4×3 输入格。输入保存在方块中，关闭界面后仍保留。左侧原料区、中间锤子、最右侧成品预览；预览槽始终显示，匹配成功后显示锤子按钮。

配方无序，每条原料占一格，可以要求该格消耗多个物品；额外未匹配原料阻止制作。点击次数、点击冷却、等级成本与成品名称键均可配置：默认 3 次、10 刻、0 级，未指定名称键时使用成品名。冷却中点击不计进度，播放较轻音效。

最后一击成功时一次扣除经验等级并消耗原料，成品直接放入玩家背包，满时掉落。关闭界面重置锤击进度；移除皮革垫返还垫与输入，不消耗铁砧耐久。

内置六条配方的原料均各一件：

| 成品 | 无序原料 | 锤击次数 | 经验等级 |
| --- | --- | ---: | ---: |
| 固相星浆 | 星浆晶胚、紫水晶碎片、星浆 | 2 | 3 |
| 南十字座的碎片 | 南十字座的投影、力量晶石、感应晶石、固相星浆 | 3 | 7 |
| 望远镜座的碎片 | 望远镜座的投影、魔力晶石、感应晶石、智力晶石、固相星浆 | 4 | 15 |
| 南三角座的碎片 | 南三角座的投影、体质晶石、敏捷晶石、魔力晶石、星浆、固相星浆 | 5 | 31 |
| 刻阶晶核 | 待锻刻阶晶胚、智力晶石、刻阶晶石、紫水晶碎片、固相星浆 | 4 | 15 |
| 盛息晶核 | 待锻盛息晶胚、体质晶石、盛息晶石、紫水晶碎片、固相星浆 | 4 | 15 |

这些经验数值属于内置配方，附属可独立定义成本。

## 投影框架组合

框架最多吸收九件材料，配方要求 2–9 步，逐步检查材料、先后顺序和叠放方向：

- `材→框`／`material_on_frame`：鼠标拿材料，右键物品栏中的框架。
- `框→材`／`frame_on_material`：鼠标拿框架，右键物品栏中的材料。

每一步消耗一件材料；不匹配任何候选配方前缀时拒绝该步，保留已有记录。完成唯一匹配配方后输出成品并消耗框架。未完成框架可在 3×3 工作台无序拆解，返还空框架与已吸收材料，保存材料的完整物品数据。

模型显示已吸收的材料，tooltip 列出当前步骤与方向。JEI 使用物品图标、箭头及右键鼠标图标表示操作。

| 成品 | 从左到右的叠放步骤，每步一件 |
| --- | --- |
| 透星片 | 玻璃板 `材→框` → 星浆 `框→材` |
| 南十字座的投影 | 力量晶石 `材→框` → 感应晶石 `框→材` → 透星片 `材→框` |
| 望远镜座的投影 | 魔力晶石 `材→框` → 感应晶石 `材→框` → 智力晶石 `框→材` → 透星片 `框→材` |
| 南三角座的投影 | 体质晶石 `框→材` → 敏捷晶石 `材→框` → 魔力晶石 `框→材` → 透星片 `材→框` |
| 并轨棱核 | 南十字座的碎片 `框→材` → 固相星浆 `材→框` → 力量晶石 `框→材` |
| 群辉晶核 | 望远镜座的碎片 `材→框` → 固相星浆 `框→材` → 魔力晶石 `材→框` |
| 折衡晶核 | 南三角座的碎片 `框→材` → 固相星浆 `框→材` → 体质晶石 `材→框` |
| 照映晶核 | 望远镜座的碎片 `材→框` → 固相星浆 `材→框` → 透星片 `框→材` |
| 六衡晶核 | 南十字座的碎片 `材→框` → 望远镜座的碎片 `框→材` → 南三角座的碎片 `材→框` → 固相星浆 `框→材` |

## 工作台衔接

并轨棱晶、聚辉晶心、折衡晶心分别由对应的南十字座、望远镜座、南三角座投影，加星浆晶胚及力量、魔力、体质晶石无序合成。三枚职业勋章也使用工作台配方，规则见[星界躯体与填充物](星界躯体与填充物.md#职业勋章)。

## 数据生成与扩展

内置两类工艺配方的来源是 [GenerateAstralProcessRecipes.java](../scripts/GenerateAstralProcessRecipes.java)。两端 `processResources` 依赖 `generateAstralProcessRecipes`，分别生成到 `data/deeprealm_4th/recipes/`（Forge）与 `data/deeprealm_4th/recipe/`（NeoForge）。修改生成器，不在构建输出中手工维护副本。

原料和产物使用完整 ItemStack，支持 NBT／组件；原料也可用 tag。数据谓词、变换回调与具名输入见 [API 指南](星界宝石系统-API扩展开发者指南.md#动态加工与徽章)和[动态加工示例](../examples/astral-kubejs/README.md)。
