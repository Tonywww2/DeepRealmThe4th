# 干旱区粘土山：材质接入与验证

## 范围与原因

“粘土山”按原版恶地理解：红沙顶部、红砂岩浅层、普通/橙色/黄色陶瓦分层山体，不是整座灰色黏土方块山。

原有干旱池已包含三种原版恶地，低矮恶地与平顶台地也已有陶瓦；缺口是 `ARID_MOUNTAIN` 地形即使选到 `minecraft:eroded_badlands`，仍统一采用砂土、泥土、石头，导致真实山体和群系不对应。

本次修复：

- 新增可扩展的 `deeprealm_4th:surface/badlands` 群系材质标签，默认包含 `badlands`、`eroded_badlands`、`wooded_badlands`。
- V5 的干旱山脊选中该标签群系时，沿用已有恶地红沙与陶瓦层；非该标签的山脊保留原材质。
- 材质在填充、基础列查询和基础高度查询中共用同一路径。标签成员每列只解析一次，不在填充每个 Y 方块时重复选群系。
- 不改高度、山体分布、河网、气候、中心或海洋；河岸表层沉积物、防漏护岸和湿列不受此适配影响。
- 已有区块不会自动重绘，需要重启客户端/服务端后查看新区块。

## 验证

双端 `compileJava` 和 `processResources` 已通过。Forge 47.4.0 / NeoForge 21.1.233 均在独立 V12 存档完成过专项验证，各 18,374 项检查，五处样本结果相同。专项命令现已移除。

当时使用 seed=42、无在线玩家、V5 的 `verification-world-vortex-v12-clay` 测试世界。验证覆盖恶地山脊、恶地平顶山、低矮恶地、普通干旱山脊、沙漠，并核对已存储 quart 群系、实际陶瓦层、基础列和基础高度。未放置测试方块或添加强加载区块。

另检查当前生成器的所有地形主题 × 干燥/湿列/护岸/河岸条件下的材质保护，覆盖山体上下界与空气/水体。

验证命令只接受项目的 seed=42 独立无人测试存档，并按真实存档目录检查，避免误在玩家世界中生成测试区块。最近一次源码清理后，双端当前地形与完整水系离线验证已通过；材质现场仍以此前独立 V12 存档的结果为参考。
