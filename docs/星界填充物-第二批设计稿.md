# 星界填充物：第二批设计稿

状态：**已按本稿实现**。八件晶石与两枚勋章已注册；晶石并入深境四层结构宝箱统一稀有池，勋章通过工作台合成。均有中英文提示和独立 16×16 贴图。原有六种基础晶石、四件主题晶石和战士勋章见[首批设计稿](星界填充物-首批扩展设计稿.md)。

后续的百分比加分与佩戴者状态规则见[比例与玩家条件设计稿](星界填充物-比例与玩家条件设计稿.md)。

## 设计边界

- 宝石承载星体力量，星座决定组合规则。本批不为宝石指定某颗正式星体，也不新增图案判定；“星座规则”仍只用开放且有效格子的正交相邻与数量条件表达。晶石在不同生态的发现地点不决定其佩戴效果。
- 全部晶石各占一格，生效类型为**唯一效果**。同 ID 可保留多件，但只结算格盘顺序中的第一件有效晶石。相邻／数量规则每件至多触发一次，不随相邻物品数量重复触发。
- 分数结算沿用基础分 → 条件／比例加分 → 转换 → 勋章。来源分数为负时，转换按 0 计算；多件转换晶石按格盘顺序消耗剩余分数。小数保留到内部结算，tooltip 显示实际规则，不把数值四舍五入后再计算。
- 新晶石只加入 `deeprealm_4th:fourth_layer` 内的既有结构宝箱。即使战利品表 ID 与原版共用，也先检查维度；主世界、下界、末地以及其他维度均不追加本批晶石。没有维度或生态加分效果。

冲突是**有向**的：两件都可以留在开放格中，同时存在时只结算沉锚晶石；移走沉锚后裂锋自动恢复。关闭格中的沉锚不参与冲突。负分只改变最终分数，不直接扣除 Minecraft 属性；勋章各自按其规则读取最终分数。这个组合主要用来验证“物品保留、效果暂时失效”的既有系统是否对玩家清晰。

## 两枚职业勋章

两枚均**不直接提供分数**，都在转换阶段结束后读取最终分数；各为唯一效果，同 ID 的后续副本不结算。不同 ID 的勋章可以与战士勋章并用，属性由装备中的星界躯体通过 Curios 提供。下面的上限是本稿的平衡提案。

| 名称与 ID 后缀 | 读取分数 `s` | 属性加成 | 校准点 | 16×16 图标要点 |
| --- | --- | --- | --- | --- |
| 疾行勋章 `wayfarer_medal` | 敏捷，最低按 0 | 最终移动速度提高 `min(30%, max(0,s) × 1%)` | 敏捷 15 → +15%；敏捷 30 及以上 → +30% | 青绿边框中一条银白斜轨，轮廓与战士勋章区分。 |
| 守御勋章 `warden_medal` | 体质，最低按 0 | 最大生命值固定增加 `min(10, max(0,s) × 0.5)` 点 | 体质 10 → +5 生命值；体质 20 及以上 → +10 | 琥珀边框与厚实盾形晶面，不添加未经确定的职业组织徽记。 |

疾行使用最终值乘算，守御使用固定值加算；生命值以点数显示。体质 10 的 +5 生命值等于 +2.5 颗心。两项加成都允许小数，佩戴／卸下时随最终分数刷新。星界躯体 tooltip 可预览攻击力、移动速度和最大生命值；佩戴时由 Curios 的属性修饰接口提供实际加成。

三枚职业勋章（含战士勋章）均采用同形工作台配方：第一行中间放金锭，第二行两侧各放一颗对应基础晶石、中央放职业器具，第三行中间放紫水晶碎片。战士使用力量晶石和铁剑；疾行使用敏捷晶石和指南针；守御使用体质晶石和盾牌。每次制作一枚勋章，材料会被消耗。基础晶石只能由本模组在深境四层目标宝箱追加，故配方保留了该维度的探索环节；勋章本身不进入宝箱池。星界躯体的生存获取及普通玩家进入深境四层的方式仍需单独设计。

## 已实施的获取节奏

保留每箱 `1/3` 基础晶石、`1/9` 主题晶石两次独立掷取。对**深境四层**的四类目标结构宝箱，额外独立掷取一次：`1/4` 概率从第二批八件晶石和[比例与玩家条件设计稿](星界填充物-比例与玩家条件设计稿.md)的十一件晶石中，按该结构候选等权选一件。下表仅列第二批晶石的候选关系：

| 结构宝箱 | 第二批候选 |
| --- | --- |
| 沙漠神殿 | 棱桥、双镜、移衡、裂锋 |
| 下界要塞 | 棱桥、余烬、折返、裂锋 |
| 丛林神庙 | 游纹、余烬、移衡、沉锚 |
| 沉船 | 双镜、游纹、折返、沉锚 |

沙漠神殿、丛林神庙和沉船的完整候选池各有 10 件，单一候选每箱概率为 `1/40`；下界要塞有 8 件，单一候选每箱概率为 `1/32`。每次成功只追加一件。维度与战利品表双重筛选沿用首批实现；自然开箱手感和结构数量仍需游戏内验收。

## Tooltip 与美术约束

固定顺序为“基础分／转换消耗 → 条件与所得分 → 深境四层来源 → 唯一效果 → 佩戴要求”。只写与实际注册规则一致的内容。例如棱桥晶石：

> 力量 +1
> 与体质晶石相邻：感应 +1
> 来源：深境四层沙漠神殿、下界要塞宝箱
> 唯一效果

六项分数和对应数值使用同一集中调色板；条件中的基础晶石名称按其分数着色。图标均为**16×16 透明像素画**，以大轮廓、少量高光和独立刻痕辨认，不绘制未经确定的星体或星座图案。文本不重复写“分数本身不提供属性加成”。
