# 深境四层世界生成

维度 ID：`deeprealm_4th:fourth_layer`。Forge 1.20.1 与 NeoForge 1.21.1 共享生成逻辑，当前配置使用 `generation_version=5`。

## 地形与生态

维度以默认坐标 `(8, 8)` 为中心形成螺旋。四条陆地股与四条虚空股交替分布；陆地及水体的布局、群系选择、基础列与高度查询共用世界坐标模型。

| 陆地股 | 生态 | 地形与水体 |
| --- | --- | --- |
| 1 | 干旱 | 沙漠、恶地、平顶台地、独立山脊及内流水系 |
| 3 | 熔岩／下界 | 下界荒地、玄武岩生态与熔岩地形 |
| 5 | 林山 | 平原、森林、丛林、山地及主干支流水系 |
| 7 | 海洋 | 岛群、大陆架、深海沟谷、沙滩与岩岸，海面 Y=64 |

海水与河水邻接虚空时，由实体岸线或护岸约束。河网采用严格下降的排水关系，结合群系温度与降水形成河道、终端湖、河岸及雪线。虚空股采用合法的虚空群系，不生成连续陆地。

星浆晶洞在深境四层的虚空中生成，使用原版 `minecraft:geode` 地物类型。生成高度为 Y=-32..128，约每 64 个虚空区块尝试一座，内壁有 2–4 个星之源。采集与生长见[星界材料与工艺](星界材料与工艺.md)。

## 配置与群系扩展

默认参数与群系池位于 [fourth_layer.json](../src/main/resources/data/deeprealm_4th/dimension/fourth_layer.json)。`parameters` 控制中心、核心范围、螺旋尺度与陆地比例；`pools` 使用群系 tag，并保留原版备用群系。

群系标签目录为 `data/deeprealm_4th/tags/worldgen/biome/`：

| 分类 | 标签后缀 |
| --- | --- |
| 干旱 | `region/arid/desert`、`badlands`、`plateau`、`mountain`、`river` |
| 熔岩／下界 | `region/infernal/nether`、`basalt` |
| 林山 | `region/temperate_tropical/plains`、`forest`、`jungle`、`mountain` |
| 海洋 | `region/oceanic/coast`、`ocean`、`deep`、`island` |
| 水文 | `hydrology/frozen_river` |

表中同一行的短后缀沿用第一个标签的目录，例如 `region/arid/mountain`。也可扩展 `region/arid`、`infernal`、`temperate_tropical`、`oceanic` 根标签；优先使用具体地形子池。完整用法见[群系兼容数据包示例](../examples/biome-compat/README.md)。

恶地式山体采用红沙、浅层红砂岩与分层陶瓦。`deeprealm_4th:surface/badlands` 决定干旱山脊的恶地材质，默认包含三种原版恶地；普通干旱山脊保留砂土／岩石。添加外部恶地山地时，可同时扩展地形群系池与该材质标签。

## 原生生成与兼容边界

生成器读取经过加载器与其他模组修改后的群系气候、地物、结构和生物列表，并保留原生过滤及生成条件。地物和结构放置仍需满足虚空、河道、湖泊与海洋护岸的保护规则。

外部模组的 noise router、surface rules、carvers 和专属维度机制不会自动移植。Biomes O' Plenty 与 Terralith 的可选标签映射及开发依赖用于群系兼容；没有安装它们也可使用本模组。

实现中的缓存、预计算和空间索引用于减少重复采样。性能受种子、群系数据包、其他模组、硬件及区块状态影响；现行指南不把历史固定样本计时作为当前服务器或客户端性能保证。

## 世界使用与检查

修改生成参数、算法或群系池后使用新世界或新区块检查；已生成区块不会自动重绘，旧世界的衔接与兼容不作保证。管理员可使用原版 `/execute in`、`/tp`、`/locate` 等命令检查维度、群系和结构。

仅在用户要求相应验证时，使用 Gradle 的 `verifyTerrain`、`verifyAstral`、`verifyWorldgenOptimization` 等任务；完整 `build` 会运行这些检查。水系专项任务 `verifyHydrology` 需要配置所指向的真实群系气候导出文件。启动与打包命令见[项目首页](../README.md)。
