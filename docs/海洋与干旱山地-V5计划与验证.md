# 海洋与干旱山地：当前实现与验证

当前深境四层只接受 `generation_version=5`。本记录说明这版海洋、干旱山地及群系兼容的现行行为；旧生成器的对照图、旧存档和实验报告不属于当前验证入口。

## 生成行为

- 第 7 股的 `MarineRelief` 在世界坐标中组合大陆、岛群、大陆架、深海沟谷、沙滩和岩岸；海水面为 Y=64。邻接虚空的水列由实体海岸或护岸封住。
- 第 1 股的 `AridRelief` 生成平顶台地与独立干旱山脊；恶地群系标签决定黏土山材质，其他干旱山脊保留原有岩石／土层。详见[黏土山材质验证](干旱区粘土山-材质接入与验证.md)。
- 第 1、5 股的主干支流水系使用世界坐标汇水区与加载器处理后的群系气候。生成后的原生河水安排流体后处理；水系与群系、地形列查询共用同一生成模型。
- 群系池由 `data/deeprealm_4th/tags/worldgen/biome/region/` 及表面材质标签扩展。可选的 Biomes O' Plenty / Terralith 开发配置见[群系兼容示例](../examples/biome-compat/README.md)。

## 验证入口

双端 `build` 自动运行 `CurrentTerrainVerification` 和 `AstralCoreVerification`。前者检查当前地形的四组生态、海陆分布、深海、沙滩、台地、山脊、连续性及确定性；它不读取旧版地形或生成旧版对照图。

完整水系离线验证需要先在当前 seed=42 验证服务器执行 `/fourthlayer verifyclimate`，导出实际注册表气候；再运行对应加载器的 `verifyHydrology`。验证包括完整汇水区、支流、湖水收支、河道连续性、河水防漏、侵蚀界限和并发确定性。此任务依赖本机气候导出，不作为普通 `build` 的前置条件。

实际服务器验证使用 `scripts/Test-HydrologyRuntime.ps1` 的 `Climate`、`Geometry`、`Biomes`、`Compat`、`Ecology`、`Prepare`、`Check`、`Cleanup` 与 `Structures` 阶段。脚本只接受当前 seed=42 的独立无人测试存档。`Check` 应在游戏正常推进至少 200 tick 后执行；测试不会手动放置河水。

## 限制

生成结果会受到种子、群系数据包和加载器群系修改器影响。修改地形参数、群系池或标签后应使用新世界验收；已生成区块不会自动重绘。结构与地物仍需遵守虚空、河道和护岸的保护边界。正式传送门和完整生存获取流程仍需另行设计。
